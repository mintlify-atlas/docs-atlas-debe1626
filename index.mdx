Interprocess gives Rust programs a unified, ergonomic interface for interprocess communication across Windows, Linux, macOS, and other Unix-like platforms. Whether you need a simple parent-to-child pipe or a full client-server local socket architecture with async Tokio support, Interprocess has you covered.

## Communication Primitives

Interprocess provides both cross-platform abstractions and OS-specific interfaces for IPC.

<CardGroup cols={2}>
  <Card title="Local Sockets" icon="plug" href="/concepts/local-sockets">
    The flagship primitive. A better alternative to `localhost` TCP — faster, with OS-enforced identity and user-friendly names. Backed by Unix domain sockets on Unix and named pipes on Windows.
  </Card>
  <Card title="Unnamed Pipes" icon="arrow-right" href="/concepts/unnamed-pipes">
    Lightweight unidirectional pipes for communicating with child processes. Inheritable handles make passing endpoints easy.
  </Card>
  <Card title="Async with Tokio" icon="bolt" href="/concepts/async-tokio">
    Enable the `tokio` feature to get async-native versions of all local socket and pipe types that integrate directly with the Tokio runtime.
  </Card>
  <Card title="Platform Support" icon="globe" href="/concepts/platform-support">
    Explicit support for Windows, Linux, macOS, FreeBSD, Android, and more. OS-specific extensions are gated behind `#[cfg]` to produce compile errors on unsupported platforms.
  </Card>
</CardGroup>
